## Corrections completed

### Generator-owned noise

`math.noise` has been removed. `Core.DeterministicNoise` implements deterministic 2D value noise with quintic interpolation over lattice values generated by the project-owned 32-bit hash. Roblox still supplies Luau arithmetic and buffers, but it no longer owns the coherent-noise algorithm or its lattice values.

### Position-sensitive signatures

The additive checksum has been replaced with 32-bit FNV-1a:

- Plan hashing folds each canonical cell index and its quantized height into the byte stream.
- Terrain hashing folds each global voxel index, material value, and quantized occupancy into the byte stream.
- Chunk captures use global voxel indices, so isolated and full-bake regions are directly comparable.
- Counts remain diagnostics only; they are not treated as discriminating hashes.

### Cross-session golden regression

`MilestoneOneGolden` stores the generator version, seed, plan signature, full-terrain signature, filled-cell count, and all sixteen chunk signatures. The runner records a non-archivable Studio-session marker. The golden check cannot set `Milestone1Passed = true` unless it runs in a later Studio session and all expected values match.

### Stronger chunk isolation test

Each of the sixteen chunks is tested in isolation:

1. Clear the complete configured terrain region.
2. Materialize exactly one chunk.
3. Read that chunk's voxel data.
4. Compare it with the same chunk captured from a complete bake.
5. Repeat for all chunks, then restore the full world.

This catches accidental dependence on neighboring writes or materialization order.

### Source-control foundation

The Studio scripts have been mirrored into a Rojo-compatible filesystem project under `src/`, with `default.project.json` at the repository root. Rojo is not installed on this machine, so live synchronization has not been claimed or tested. The mirror is ready to commit and can become the source of truth before Milestone 2.

- `GeneratorVersion = "1.0.0-m1"` is stored in the world specification and `Workspace.WorldRoot` diagnostics.
- The detailed full-suite report and golden-regression report are stored separately.
